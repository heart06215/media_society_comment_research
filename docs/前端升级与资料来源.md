# 前端升级与资料来源

资料核验日期：2026-10-30。

## 项目定位

破妄现定位为“网络生态治理与立法研究支持平台”：以社区评论的语境分类、证据追溯和人工复核，辅助发现疑似刷评、相互攻击等治理问题，并整理规则研究素材。首页按“数字经济背景 → 社区生态研判 → 原始证据 → 现行规则 → 研究提纲”组织演示。

模型分类不直接构成违法认定，也不能单独证明付费刷评或账号身份。当前研究范围为已配置的视频社区样本，不能外推到全网。模型置信度、采集样本覆盖率均不代表准确率；准确率应由独立标注测试集评估。

## 页面与交互

| 路径 | 用途 |
| --- | --- |
| `/` | 治理总览、数字经济环形图及增长折线、社区筛选、评论证据、规则参考、AI 问答及研究文件导出 |
| `/comments` | 原始评论、分类及关键词筛选、排序、详情；支持 `bvid`、`category`、`q` 深链接 |
| `/insight` 或 `/insight.html` | 保留原有社区结构、时间趋势、双社区对比和关系图谱 |
| `/label` | 保留人工标注、模型结果复核及分析入口 |

首页统计读取 `/api/videos`，证据详情读取 `/api/comments`。首页没有虚构演示数据兜底；加载失败时显示重连入口，空数据时引导建立样本。代表性评论保持原文，长文本可展开，跳转使用 Unicode 码点截取关键词，避免截断 emoji。

两种 Markdown 导出分别提供完整治理研究摘要和立法研究提纲，包含研究问题、证据整理要求、官方规则链接及数据边界。提纲为人工研究起点，不是自动完成的立法建议书。

首页经济图表用原生 SVG 实现，无需图表 CDN。保留的深度洞察及关系图谱仍使用原有 ECharts CDN。AI 助手继续使用项目已有的 `/api/agent/chat` 和模型配置，支持停止等待、失败反馈及问题保留。

## 视觉约定

使用场景：竞赛评委和研究人员在明亮室内桌面浏览器中，快速理解项目价值，再逐步追溯图表、评论和研究依据。按用户要求保留原 UI 的包豪斯 × 构成主义风格：电光蓝 `#2743FF`、荧光青 `#00D9E9`、紫色 `#6E1EFF`、品红 `#F22560`、点缀黄 `#FFD400`，使用黑白粗线条、方角、描边字、几何标志与图纸网格。

设计参数：`VISUAL_VARIANCE=6`、`MOTION_INTENSITY=2`、`INFORMATION_DENSITY=6`。仅使用状态反馈与锚点滚动，支持减少动态效果偏好。全部四个页面共用左侧导航，手机端使用可关闭的左侧抽屉；顶部只保留当前位置与主题切换，不再重复放置页面入口。

导航由 `front/workspace.js` 统一维护，顺序为：治理总览、社区生态研判、立法研究支持、数字经济观察、AI 治理助手，以及社区深度洞察、评论关系图谱、评论证据库、人工标注与复核。提供当前页面或区段高亮、跨页锚点跳转、键盘焦点限制和 Escape 关闭。

项目没有独立 `DESIGN.md`。本次保留 `front/base.css` 的原有 v2 色板，`front/governance.css` 的 `--gov-*` 颜色引用该色板，`front/tools.css` 负责子页面的布局适配。后续扩大界面规模时，建议专门整理设计规范。未额外生成设计规范文件。

## 2026-11-02 阅读尺度与叙事调整

本轮仅采用全国一、二、三等奖范围内的项目作为参考，不采用校奖、省奖或奖级不明确的项目。核验了“灵犀舆情”和“面过 Mango”的上述高校官方介绍，以及[Sumisound 全国一等奖项目介绍](https://hainan.cuc.edu.cn/2026/0903/c8811a273534/page.htm)。公开介绍所体现的“具体问题、处理流程、使用场景与成果输出”被转化为本项目的内容安排，不将参考作品的能力写成破妄已有功能。

- 首页顺序调整为：问题与研究工作单 → 样本规模 → 社区线索与评论证据 → 人工复核与规则研究 → 数字经济背景 → AI 追问与来源说明。宏观经济数据不再先于项目自身的研究证据出现。
- 用可操作的“找原文、看关联、做复核、提问题”研究工作单替换装饰性环形流程；删减重复口号和过长英文眉题，保留原色板、粗边框、描边字与几何标志。
- `base.css` 统一定义 `--type-*` 字号：正文 18px、辅助信息 14–16px、导航与操作 16–18px、详情正文 20px、关键统计数字 56px。页面内样式、动态生成内容与 ECharts 字号同步提升。
- 评论证据库采用 112px 高、至少 176px 宽的紧凑卡片和 4px 间距；1440px 桌面每行 6 张，原布局为每行 4 张、144px 高。卡片摘要 16px，辅助数字 14px，详情保留完整原文与置信度。六分类汇总折叠，手机筛选横向滚动，评论保持双列。
- 其他页面保持宽松阅读；窄屏统计块使用单列，避免大数字被截断。数字经济 SVG 按容器宽度重新布局，窄屏保留首尾和当前选中年份的数值，完整序列继续通过图表说明和来源表提供。

设计参数更新：`VISUAL_VARIANCE=6`、`MOTION_INTENSITY=2`；总览与研究页 `INFORMATION_DENSITY=5`，评论证据库 `INFORMATION_DENSITY=9`。共享字号位于 `front/base.css`，可分别调整正文、标题、指标和辅助信息。

本轮验证：四页与修改资源接口正常；1440px 桌面及 320px 手机检查未发现页面横向溢出，1024px 复查首页与标注页；窄屏统计数字无截断。实测年度/指标切换、评论筛选、详情弹窗及 Escape 关闭、手机左侧导航跳转。未调用模型或保存人工标注。

## 2026-11-02 迷惑性评论与规则缺口

本轮把“令人迷惑的评论难以辨认”作为产品主问题。这里的不可辨认性指文本脱离语境后不足以可靠确定立场、对象或行为动机，不宣称任何评论永久不可理解。反讽、圈层黑话和复读以三组构造情境演示，始终标明“非采集样本”，不进入样本统计或效果评测。

首页采用“体验一次误读可能性 → 解释难辨机制 → 提出规则细化问题 → 查看真实样本与人工复核 → 了解发展背景与继续追问”的顺序。共享左栏新增“评论为何难辨”，立法入口改为“立法与规则缺口”，四页统一为十个导航入口。保留大字号、原色板、几何风格和紧凑评论墙。
