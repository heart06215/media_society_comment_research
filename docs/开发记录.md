# 开发记录

项目：基于微调大模型的对互联网社区评论情感分析（"破妄"）。本文汇总此前工作痕迹中的改造记录，按日期与主题排列。

## 2026-10-21

### 启动破妄.bat 打不开项目

- 原因：原来用 `start /B python app.py`，批处理跑完控制台一关，子进程跟着被杀；浏览器又固定等 4 秒就打开，服务还没起来。两个问题叠在一起就是页面打不开。
- 改法：
  - 解释器按 `.venv` → `python`/`py`（要求能 `import flask`、`flask_cors`）→ `D:\python\python.exe` 顺序探测；
  - 先探 5000 端口 `/health`，已在跑就直接开浏览器；
  - 没跑就在本窗口前台执行 `app.py`，另起一个隐藏 PowerShell 轮询 `/health`，200 之后再 `Start-Process` 开页面；
  - 不再用 `timeout /t`（这台机器 PATH 里有 git bash，会撞上 GNU timeout 报 invalid time interval），等待全放进 PowerShell；
  - 服务异常退出会停在 `pause`，能看到 traceback。
- 实测冷启动通过：识别到 `py`，服务起来，浏览器正常打开。
