## 优先开发顺序

1. **先补 AI 证据。** 固定训练、检索和独立测试划分，排除重复及同源泄漏。比较词典、零样本、检索增强、已完成微调的模型；记录 Macro-F1、各类召回、耗时和费用。尚未完成的实验不填虚构结果。
2. **完成可追溯研究流程。** Agent 展示所调用工具、数据范围、评论证据及法规出处；生成建议时区分观察事实与研究推论。现有网络用语检索不等于法规 RAG，法规检索需单独建设、验证引用准确性与时效。
3. **补 AI 安全与多模态。** 测试提示注入、无数据、模型超时和错误分类。多模态目前缺少可验收实现，可围绕经授权的视频字幕或截图补充上下文，并标记来源和人工确认；不为拿分增加无关入口。网页允许 Function Calling 或 MCP，已有工具调用应先提供真实运行证据。
4. **再补工程和试用。** 将长页面按功能逐步拆分，保留原 UI 配色和统一左侧导航；完成桌面、手机及关键接口检查，收集真实试用反馈。
5. **最后整理提交与答辩。** 用同一版本的代码、视频和文档讲述一条案例，解释方法局限、数据口径、实际贡献与失败样例。

当前快照为 2 个视频、7,199 条评论、107 条人工锚定记录，属于有限样本。“水军”等现有标签只能作为待核查线索；重复表达、情绪分布或模型置信度不能证明违法、组织操控或付费身份。项目定位为辅助研究、人工复核和治理建议，不替代执法认定。
